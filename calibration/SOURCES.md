# imatrix calibration set: sources

`calibration.txt`: 883 chunks, **710,548 tokens** (DeepSeek-V4.1 tokenizer), 2,712,455 bytes. Each chunk is 512–2048 tokens. Chunks are shuffled and separated by a blank line.
To rebuild: `python3 fetch.py raw` (pinned revisions), then `python3 -I build_calibration.py raw <tokenizer.json> calibration.txt`. Seed 20261101. The output is byte-identical across runs (md5 `e89e9a932b225f4f38cb57c9ef1fcef0`).
Chat and agent data is rendered with the model's own role tokens (`<｜System｜>`, `<｜User｜>`, `<｜Assistant｜></think>…<｜end▁of▁sentence｜>`). Tool outputs appear as user turns.

## Rejected
- `nebius/SWE-agent-trajectories` (CC-BY-4.0): its card adds "if you intend to use the outputs of these models, you must comply with the Llama 3.1 License". That is a non-permissive encumbrance.
- CommitPackFT rows under agpl-3.0, lgpl-2.1, mpl-2.0, epl-1.0, artistic-2.0 or `unknown`: excluded by the per-row filter.
- `allenai/openbookqa`: card says `license: unknown`.
- `Salesforce/xlam-function-calling-60k`: gated, with extra terms of use.
- `bigcode/self-oss-instruct-sc2-exec-filter-50k`: ODC-BY, and its outputs come from StarCoder2 (OpenRAIL); not needed.
- WikiText test/validation and MATH/GSM8K test splits: not rejected on license grounds. Avoided so evaluation sets stay uncontaminated.
